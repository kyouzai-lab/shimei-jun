# あてる順

授業で当てる順番を座席表の上で決めて、順に光らせていく先生用の道具。iPad の横向きが前提（縦向きでも使える）。

- 入口：`index.html` 1枚（ビルドなし・ライブラリなし。文字だけ Google Fonts を読む）
- 保存：合言葉で暗号化して localStorage のキー `shimei-jun:v3` に置く（くわしくは「しくみ」）。名前はその端末の中だけで、ほかへは送らない

## しくみ

- 2026-11-28 から保存のしかたが変わった。前は `shimei-jun:v2` に読める形（平文）で置いていたが、kyouzai-lab.github.io の教材は全部同じ保存場所を使うので、ほかの教材のページからも読めてしまっていた
- いま：合言葉から PBKDF2（SHA-256・25万回）で鍵を作り、AES-GCM 256bit で暗号化して `{ v, salt, iv, ct }` を `shimei-jun:v3` に保存する。合言葉と鍵は保存しない（鍵は開いているあいだメモリの中だけ）
- 合言葉は6文字以上。はじめて開くと合言葉を決める（2回入力）。次からは合言葉を入れて開く。5回まちがえると30秒待ち（`shimei-jun:fail`）。「合言葉を忘れたとき」は全部消して最初から
- 前の版の `shimei-jun:v2`（ともっと前の `shimei-jun:order`）が残っていたら、はじめて合言葉を決めたときに読みこんで暗号化し、保存できたのを確かめてから平文のほうを消す
- ロックするとき：右上の「ロック」、ページを開き直したとき、「3 当てていく」から先生の画面（1・2）にもどるとき（せきがえの発表画面と同じ考え方）。しばらく操作がないときの自動ロックはしない（授業中に止まらないように。せきがえも同じ）
- せきがえの「あてる順から読みこむ」は、あてる順の合言葉を聞いて `shimei-jun:v3` を開いて読む。まちがいは `shimei-jun:fail` にかぞえる
- CSP で外とのやりとりはできない（文字の形の Google Fonts だけ）

## 画面

1. **じゅんび**：座席の並び（よこ1〜10列・たて1〜8行、はじめは6列×4行、2人ずつ並べる、机をなくす）、名簿（出席番号の順。Excelのたて1列を1番のらんに貼ると下へ順に入る）、席をタップして出席番号をえらぶ
2. **順番を決める**：当てたい順に席をタップ。選んだ人に考え方（A〜E・いくつでも）・グループ（①〜⑥・1つ）・一行メモをつけられる。ボタンの文字は名簿画面で変えられる
3. **当てていく**：次の人の席が光る。「次へ」で進み、当てた席は灰色に「済」。右側に名前・考え方・メモ・つぎの人

教卓のよこの「⇅ 上下反対」で、教卓が上の向き（教卓から見た向き。左右も入れかわる）になる。

## データの決めごと

- 座席の番号 i ＝ 教卓がわから r 行目・左から c 列目 → `i = r * cols + c`。行をふやすと後ろに、列をふやすと右に足す
- 列・行をへらしてはみ出す席に番号や順番があるときは確かめてから消す
