# あてる順

授業で当てる順番を座席表の上で決めて、順に光らせていく先生用の道具。iPad の横向きが前提（縦向きでも使える）。

- 入口：`index.html` 1枚（ビルドなし・ライブラリなし。文字だけ Google Fonts を読む）
- 保存：localStorage のキー `shimei-jun:v2`（名簿・座席・当てる順とメモ・並び）。名前はその端末の中だけで、ほかへは送らない

## 画面

1. **じゅんび**：座席の並び（よこ1〜10列・たて1〜8行、はじめは6列×4行、2人ずつ並べる、机をなくす）、名簿（出席番号の順。Excelのたて1列を1番のらんに貼ると下へ順に入る）、席をタップして出席番号をえらぶ
2. **順番を決める**：当てたい順に席をタップ。選んだ人に考え方（A〜E・いくつでも）・グループ（①〜⑥・1つ）・一行メモをつけられる。ボタンの文字は名簿画面で変えられる
3. **当てていく**：次の人の席が光る。「次へ」で進み、当てた席は灰色に「済」。右側に名前・考え方・メモ・つぎの人

教卓のよこの「⇅ 上下反対」で、教卓が上の向き（教卓から見た向き。左右も入れかわる）になる。

## データの決めごと

- 座席の番号 i ＝ 教卓がわから r 行目・左から c 列目 → `i = r * cols + c`。行をふやすと後ろに、列をふやすと右に足す
- 列・行をへらしてはみ出す席に番号や順番があるときは確かめてから消す
